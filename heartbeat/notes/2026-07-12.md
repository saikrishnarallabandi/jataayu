# Group-reply guard unblock note - 2026-07-12

Sai's request after the Jataayu group-reply guard failure: "We could change it so we mask out pii and send na".

Decision/request:
- For group replies that fail because of PII or protected context, run a deterministic masking/scrubbing pass first.
- Re-run safety classification on the scrubbed text, not on the original unsafe draft.
- If the scrubbed group reply is safe, send that sanitized reply.
- LLM rewrite can be an optional polish layer after deterministic scrubbing, but it must not be the only unblock path.
- If the scrubbed reply still classifies unsafe, refuse/hold rather than sending.
