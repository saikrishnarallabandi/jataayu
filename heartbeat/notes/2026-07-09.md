# SafeHarbor benchmark + ICML 2026 comparison — 2026-07-09

## What this pass did

Answered two prompts: (1) go through SafeHarbor (arXiv:2605.05704), is it better than Jataayu,
benchmark Jataayu against its dataset; (2) compare Jataayu against the ICML 2026 security papers,
with numbers. Two memos + a new reproducible harness landed.

## SafeHarbor — the read

SafeHarbor is a trained misuse **guardrail** (7B + "Risk-Tree" attack memory + MLP "Safety Projector";
14 GB, 307 ms). It reads the agent **trajectory** and refuses harmful ones. Adversary = the malicious
**user** (direct misuse). Indirect injection is explicitly **not** its threat model; it never compares
to CaMeL/FIDES/provenance work. Confirmed ICML 2026 poster 64556. Headline (GPT-4o): harm-score 6.3,
harmful-refusal 93.2%, benign-refusal 25% (benign utility 63.6%). Its real claim is the utility/safety
*trade-off*, not raw refusal (LlamaGuard-3 beats it on refusal).

**Verdict: not "better than what we have" — a different axis.** SafeHarbor separates harmful-vs-benign
INTENT on trusted user input (~68 pt separation). Jataayu gates EFFECTS by provenance and is
intent-blind by design. Complementary layers.

## Benchmark — Jataayu on AgentHarm (SafeHarbor's dataset)

New harness: `eval/run_agentharm_effect_boundary.py`. Result: `eval/results/agentharm_effect_boundary.json`.
Pulled AgentHarm public (208 harmful + 208 benign), mapped its 85 synthetic tools -> `EffectClass`
(map emitted in the JSON, fully auditable), ran the REAL `EffectBoundary._decide` over each behavior's
`target_functions`. A behavior is blocked if any tool gets DENY/NEEDS_APPROVAL.

| Framing | harmful block/hold | benign block/hold | intent separation |
|---|---|---|---|
| Injection (untrusted) — native setting | **94.2%** (40.4% DENY) | 92.3% | +1.9 pt |
| Direct-misuse + restrictive policy (trusted) | 94.2% (all DENY) | 92.3% | +1.9 pt |
| Direct-misuse + permissive (trusted) | 0.0% | 0.0% | 0.0 pt |
| Out-of-box (no tool registration) | 30.8% | 30.8% | 0.0 pt |

SafeHarbor GPT-4o for contrast: 93.2% / 25% -> ~68 pt separation.

Reading: Jataayu **matches** SafeHarbor's harmful-block rate (94.2 vs 93.2) deterministically, sub-ms,
0 VRAM — but its separation is ~2 pt because the discriminator is provenance × severity, not intent.
The 12 harmful it never blocks (5.8%) are all pure web-search/info chains (READ-only, informational
harm, no effect fires) = exactly SafeHarbor's domain. Out-of-box 30.8% is the honest deployment caveat:
custom agent tools must be registered to an effect map (a one-time config step, done here).

## ICML 2026 comparison — the landscape

Doc: `docs/icml2026-security-comparison-2026-07-09.md` (4 parallel survey agents, all arXiv IDs verified,
anchored on `github.com/jiaxianyan/icml-2026-agent-papers`).

- **Jataayu's effect-boundary/IFC family is absent from ICML 2026 main track.** CaMeL -> SaTML 2026,
  ControlValve -> ICLR 2026, FIDES/AgentArmor/AuthGraph/arXiv:2606.09549 -> arXiv. ICML 2026 hosts the
  *guardrail* family (SafeHarbor, CausalArmor, BARRED, EMBGUARD, SkillGuard) — the other axis. Natural
  venue for us = SaTML/ICLR/S&P.
- **AgentDojo scoreboard (real repo runs):** Jataayu meets the 0% ASR bar. workspace/qwen3.6-35b
  (70 attack cases): ASR 2.9% -> **0.0%** at **zero** utility tax. Cohort bar = 0–3% ASR at <=7 pp tax
  (CaMeL 77% provable @7pp; AgentArmor 3% @1pp; ControlValve ~0 @3pp; AuthGraph 1% @76% util).
- **Two mechanism collisions to differentiate against:** arXiv:2606.09549 (opaque-handles +
  PREVIEW->COMMIT, near-verbatim ours; ASB 0% / AgentDojo 0.64%) and AuthGraph (2605.26497 —
  provenance × authorization; 40->1% ASR). Our differentiator = the 3-factor **severity-graded** gate.
- **Per-module competitors (numbers):** SkillVetBench (static misses 89%), SCR-Bench (TrustLift 96.5% /
  CapFlow 33.6% / AuthBlur +71.8%), sleeper-memory attacks (Hidden-in-Memory 99.8% implant; MemMorph
  85.9%) vs defenses TMA-NM (0% formal), MemAudit (->0%), Forensic Signatures (AUC 0.99).

## The one wart

gpt-5.4-mini AgentDojo run (`agentdojo_workspace_gpt54mini_oauth_true_full.json`): ASR already 0->0,
but Jataayu drops no-attack utility 47.5% -> 25% (~20 pp over-block). qwen3.6-35b is clean at 0 pp, so
this is a **model-specific false-positive** problem, not a design flaw — but it's the **#1 fix before
any AgentDojo headline** (whole cohort competes at <=7 pp tax). Tracked P0 in `NEXT.md`.
